# Multimodal Personal Knowledge Base

## Overview
An intelligent knowledge management system with semantic search, AI-powered content analysis, and personalized recommendations.

## Features
- 🔍 Semantic search using Sentence-BERT embeddings
- 🤖 AI-powered content analysis (summarization, keywords, entities)
- 📊 Intelligent recommendation engine
- 🔗 Automated connection discovery
- 📱 Responsive MERN stack architecture

## Tech Stack
- **Frontend**: React, Material-UI
- **Backend**: Node.js, Express
- **Database**: MongoDB Atlas with Vector Search
- **AI**: Google Gemini API, Sentence-Transformers
- **Auth**: JWT, bcrypt

## Installation

### Prerequisites
- Node.js 18+
- MongoDB Atlas account
- Google Gemini API key
